薪酬福利与管理制度

第一章 总则

概述

为建立科学、公平的薪酬激励体系，规范员工行为，提升工作效能，特制定本制度。本制度适用于公司全体在职员工。

第二章 薪资结构标准

公司实行“基本工资 + 满勤奖 + 绩效奖金 + 销售提成”的复合薪资结构。具体标准如下：

特别说明：本章所列薪资标准为通用指引。员工的具体薪资数额、构成及试用期时长等，均以员工个人签署的《劳动合同》中约定的条款为准。

2.1 试用期薪资 (为期3个月)

  • 第一至第二个月： 试用期基本工资 + 满勤奖 200元
  • 第三个月： 试用期基本工资 + 满勤奖 200元 + 绩效奖金 (基数500元)
    *注：绩效奖金将根据第三章的考核标准进行核算，实际发放金额在0元至500元之间浮动。

2.2 转正后薪资

  • 月度薪资构成： 转正基本工资 + 满勤奖 200元 + 绩效奖金 (基数500元) + 销售提成
  • 计算公式： 月度应发工资 = 转正基本工资 + 满勤奖 200元 + 绩效实发金额 + 销售提成
    *注：绩效奖金和销售提成将根据本章及后续章节标准核算。

第三章 绩效考核管理办法（试行）

绩效考核旨在激励员工高效完成核心工作任务，奖金与业绩直接挂钩。绩效奖金总额为500元/月，由以下两部分组成：

3.1 核价链接考核 (权重70%，满分350元)

  • 考核指标： 当月独立完成并通过审核的、核价合理的产品链接数量。
  • 考核标准： 每月基础任务量为 30条。
  • 核算方式：
    • 完成30条及以上，该项绩效得满分 350元。
    • 完成数量未达15条，该项绩效不得分。
    • 超过15条未达到30条，按实际完成数量与基础任务量的比例核算得分。
      • 计算公式：
      • 当月实际完成合格链接数 > 15 ：
        核价绩效实发金额 = (当月实际完成合格链接数 / 30) × 350元
      • 当月实际完成合格链接数 <= 15 ：
        0元
  • 说明： “核价合理”的最终解释权归直属上级或指定负责人所有。

3.2 返单考核 (权重30%，满分150元)

  • 考核指标： 当月成功促成的链接返单数量。
  • 考核标准： 每月基础任务量为 3条。
  • 核算方式：
    1. 完成3条返单，该项绩效得满分 150元。
    2. 每超出1条返单，额外奖励 50元。上不封顶。
    3. 若未完成3条，则该项绩效按实际完成比例核算，最低为0元。
    • 计算公式： `返单绩效实发金额 = (当月实际返单数 / 3) × 150元 + (MAX(当月实际返单数 - 3, 0)) × 50元`

3.3 绩效总分计算

  • 月度绩效实发总额 = 核价链接考核实发金额 + 返单考核实发金额
  • 绩效奖金随当月工资一并发放。

第四章 考勤管理规定

公司采用企业微信进行数字化考勤管理，全体员工须严格遵守。

4.1 工作时间与休息日

  • 固定休息日： 每周 星期日 为统一休息日。
  • 额外假期： 每月享有 1天 额外自由假期，当月有效，不可累积或结转至下月。
  • 工作时间： 周一至周六（除周日及自由假期外）
    • 上午：09:30 — 12:00
    • 下午：14:00 — 18:30

4.2 打卡规定

  • 强制打卡点： 每日 上午09:30前 需完成上班打卡，下午18:30后 需完成下班打卡。此为判定迟到、早退的唯一依据。

4.3 请假、调休与审批

  • 所有请假、调休均需至少提前 一个工作日 的 工作时间 内，通过 企业微信 提交审批流程。
  • 未经审批擅自休假者，一律按旷工处理。

4.4 补卡机制

  • 每月每人享有 3次 补卡机会。
  • 如因特殊原因忘记打卡，需在 48小时（2个工作日）内 通过企业微信申请补卡，并注明原因，经审批后方可生效。逾期未申请或超出次数限制，视为缺卡。

4.5 迟到、早退、缺卡与旷工处理细则

违纪情形 处理办法
迟到/早退 10分钟以内 每次扣款 10元，在当月工资中体现。
迟到/早退 10-30分钟 或 缺卡 每次扣款 50元，在当月工资中体现。
（注：忘记打卡且在规定时间内未能成功补卡者，按“缺卡”处理。）
迟到/早退 超过30分钟 按 旷工半天 处理。
旷工 旷工期间扣除 双倍 日工资。连续旷工3天或月累计旷工5天以上者，视为严重违反公司规章制度，公司有权予以辞退。
请假 请假期间扣除 单倍 日工资。

注：为体现公平性及符合国家相关法规，日工资将根据当月实际应出勤天数进行计算。具体公式为：日工资 = 当月应发工资总额 ÷ (当月总天数 - 当月固定休息天数)。其中，当月固定休息天数 = 当月周日天数 + 1天额外自由假期。“日工资”用于核算迟到、早退、旷工及各类请假情形的工资扣除。

第五章 销售提成方案 (多平台统一管理)

为激励各平台销售业绩增长，实现员工与公司的共赢发展，公司设立统一的销售提成奖励制度。本制度的核心目标是激励员工在所有合作平台上最大化创造“可分配利润”，并据此进行收益分配。

5.1 核心概念与核算框架

为实现跨平台激励的统一与公平，特定义以下通用框架：

  • 可分配利润 (Distributable Profit): 指员工所负责管理的任一平台店铺，在扣除该平台直接成本与公共分摊成本后所创造的、可用于激励分配的初步利润。此数据为核算销售提成的唯一依据，与平台类型无关。
  • 核算总公式:
    可分配利润 = 平台结算总金额 - Σ(该平台直接成本) - 公共固定成本分摊
  • 公共固定成本分摊: 指由公司承担的、无法直接归属单一店铺的公共开支，主要包括房租、水电、基础网络及全员共享的固定资产折旧。由公司所有店铺（不分平台）平均分摊。

5.2 各平台直接成本构成细则

不同平台的商业模式差异较大，其直接成本构成亦不相同。具体如下：

  • TEMU平台 (全托管模式):
    • 公式: `可分配利润 = TEMU结算总金额 - 商品供货成本 - 头程物流费用 - 平台综合服务费`
    • 成本释义:
      • 商品供货成本: 商品的采购成本。
      • 头程物流费用: 将商品运至TEMU国内仓库的费用。
      • 平台综合服务费: TEMU平台一次性扣除的佣金、技术服务等费用总和，以TEMU官方结算账单为准。
    • 职责定位: 核心职责为选品、供应链管理、库存规划及商品表现优化。
  • TEMU平台 (半托管模式):
    • 公式: `可分配利润 = TEMU结算总金额 - 商品供货成本 - 头程物流费用 - 平台综合服务费 - 尾程物流费`
    • 成本释义:
      • 商品供货成本: 商品的采购成本。
      • 头程物流费用: 将商品运至指定仓库的费用。
      • 平台综合服务费: TEMU平台一次性扣除的佣金、技术服务等费用总和，以TEMU官方结算账单为准。
      • 尾程国际物流费: 从仓库派送至海外消费者手中的全部物流费用。此项为半托管模式的特有且主要成本。
    • 职责定位: 核心职责为选品、供应链管理、库存规划、物流渠道管理及成本控制。
  • TikTok Shop (TK) 全托管模式:
    • 公式: `可分配利润 = TK结算总金额 - 商品供货成本 - 头程物流费用 - 平台综合服务费`
    • 成本释义:
      • 商品供货成本: 商品的采购成本。
      • 头程物流费用: 将商品运至TK国内指定仓库的费用。
      • 平台综合服务费: TK全托管模式下的平台佣金与服务费总和，以TK官方结算账单为准。
    • 职责定位: 核心职责为选品、供应链管理、库存规划及商品表现优化。
  • TikTok Shop (TK) 自运营(Self-operated)模式:
    • 公式: `可分配利润 = TK结算总金额 - 商品供货成本 - 头程物流费用 - 平台综合服务费 - TK站内广告推广费`
    • 成本释义:
      • 商品供货成本: 商品的采购成本。
      • 头程物流费用: 将商品运至TK国内指定仓库的费用。
      • 平台综合服务费: TK自运营模式下的平台佣金、支付手续费等，以TK官方结算账单为准。
      • TK站内广告推广费: 员工在TK平台内进行的付费推广所产生的费用，如Ads广告、Promote加热工具等。
    • 职责定位: 核心职责除供应链管理外，还包括店铺日常运营、内容营销、直播带货、广告投放与优化。

5.3 统一提成比例

为简化管理并明确激励导向，员工的销售提成比例将根据其当月创造的“可分配利润”总额，按统一的固定比例计提。经公司审慎评估，全平台、全模式的提成比例固定为 10%。此比例旨在平衡即时激励与公司长期、可持续发展的健康利润空间。

5.4 核算与发放规则

  • 提成计算公式: 月度销售提成 = 当月可分配利润总额 × 10%
  • 举例说明 (TEMU半托管): 某员工负责TEMU半托管店铺，当月数据如下：TEMU结算总金额200,000元，商品供货成本60,000元，头程物流费用15,000元，平台综合服务费20,000元，尾程国际物流费40,000元。公司当月公共固定成本为7000元，共有2个店铺（含此店）。
    ① 核算可分配利润：`200,000 - 60,000 - 15,000 - 20,000 - 40,000 - (7,000 / 2) = 58,500元`。
    ② 按固定比例计算销售提成：`58,500元 × 10% = 5,850元`。
  • 销售提成数据由财务部每月核算，并经直属负责人复核后，随当月工资一同发放。

第六章 附则

  • 本制度自发布之日起正式生效。
  • 公司有权根据经营状况与发展需要，对本制度进行修订，修订后将另行通知。
  • 本制度最终解释权归公司所有。

第七章 薪酬发放管理

  • 发薪日：公司实行月薪制，定于每月15日为发薪日，发放上一个自然月的工资。
  • 发放形式：员工工资将通过银行转账方式发放至员工指定的个人银行账户，如遇法定节假日或休息日则提前至最近的工作日发放。
  • 薪酬保密：公司为保障全体员工的隐私权与薪酬体系的公平性，实行严格的薪酬保密制度。任何员工不得私下打听、议论、泄露本人或他人的薪酬信息。违反此规定者，将视为严重违反公司规章制度，公司有权给予相应处分。

第八章 制度的修订与版本控制

  • 版本号与生效日期: 本制度为动态文件，首个版本号为 V1.0，自 【2025年12月01日】 起生效。任何对制度内容的修改都将生成新的版本号（如V1.1, V2.0）并更新生效日期。
  • 修订记录: 所有版本的修订历史将在此处或公司内部平台（如企业微信/钉钉公告栏）进行公示。公示内容应包括：版本号、修订日期、修订人及主要修订内容摘要。
  • 示例修订记录:
    • V1.1 (【2025年12月03日】):核价链接考核15条以下无当前项绩效,提成比例调整为10%
  • 确认方式: 员工对制度内容的确认，以其对最新版本的知晓为前提。公司通过内部平台发布公告，即视为已履行告知义务。员工有责任主动查阅并理解最新制度。
